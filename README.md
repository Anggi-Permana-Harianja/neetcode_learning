# NeetCode Learning — My DSA Journey

This repo is my personal record of learning **Data Structures & Algorithms**, following the [NeetCode](https://neetcode.io) roadmap.

## Why DSA still matters in the age of AI

AI is writing more and more code every day — but that's exactly why fundamentals matter more, not less. Anyone can prompt a model to produce a working solution. What separates a **great engineer (and a great company)** from a **mediocre one** is whether they understand *why* that solution works, when it breaks, and how to reason about it when the AI gets it wrong.

The gap between great companies and mediocre ones isn't AI adoption — it's that mediocre companies stop emphasizing fundamentals like DSA, assuming tools will cover for it. That gap is exactly what I'm trying to stay on the right side of.

So this repo exists to build that muscle deliberately: patterns, tradeoffs, and problem-solving instincts that don't go stale just because a new model shipped.

## Approach

- Solve problems by hand first — no AI assistance on the first attempt.
- Only reach for explanations/AI after struggling, to compare approaches and fill gaps.
- Revisit weak topics instead of just moving forward for coverage's sake.

## Goal

Build enough fundamental strength in DSA that it becomes a durable advantage — not something that erodes as tooling changes.
