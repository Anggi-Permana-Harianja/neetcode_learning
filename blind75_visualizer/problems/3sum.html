Approach
nums = [-1, 0, 1, 2, -1, -4] → [[-1,-1,2], [-1,0,1]]
  1. Sort the array so duplicates sit next to each other and two pointers can work.
  2. Fix the first number nums[i], then use two pointers on the rest to find pairs summing to -nums[i].
  3. Skip duplicate values for i and for the left pointer to avoid duplicate triplets.
  4. Move the pointers inward based on whether the current sum is too low or too high.
