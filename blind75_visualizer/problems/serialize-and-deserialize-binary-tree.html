Approach
[1,2,3,null,null,4,5] → "1,2,#,#,3,4,#,#,5,#,#" → same tree
  1. Serialize with preorder DFS, writing '#' for every None child so structure is unambiguous.
  2. Join values with a delimiter (comma) into one string.
  3. Deserialize by reading tokens in the same preorder sequence: a '#' means None, otherwise build a node and recurse for its left then right child.
  4. An iterator over the split tokens keeps the recursive rebuild in lockstep with the serialized order.
