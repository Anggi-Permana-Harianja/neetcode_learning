LeetCode #48 · Rotate an n x n matrix 90 degrees clockwise, in place.

solution.pyO(n²) time · O(1) space
1from typing import List2 3class Solution:4 def rotate(self, matrix: List[List[int]]) -> None:5 n = len(matrix)6 for i in range(n):7 for j in range(i + 1, n):8 matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]9 for row in matrix:10 row.reverse()
Time O(n²) Space O(1)
Approach
[[1,2,3],[4,5,6],[7,8,9]] → [[7,4,1],[8,5,2],[9,6,3]]
  1. A 90° clockwise rotation equals: transpose the matrix, then reverse each row.
  2. Transpose in place by swapping matrix[i][j] with matrix[j][i] for j > i.
  3. Then reverse every row — the combination produces the rotated result without extra space.
