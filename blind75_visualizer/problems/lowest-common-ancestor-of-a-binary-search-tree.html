LeetCode #235 · Find the lowest node that has both p and q as descendants, in a BST.

Approach
root = [6,2,8,0,4,7,9], p = 2, q = 8 → 6
  1. Use the BST property instead of general tree search: at each node, compare both target values to node.val.
  2. If both p and q are smaller, the LCA must be in the left subtree — move there.
  3. If both are larger, move right.
  4. The first node where they diverge (or match) is the split point — the LCA.
