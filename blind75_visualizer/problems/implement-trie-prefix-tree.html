Time O(m) per operation, m = word length Space O(total characters inserted)
Approach
insert("apple"); search("apple") → True; startsWith("app") → True
  1. Each TrieNode holds a map of character → child node, plus an 'end of word' flag.
  2. insert: walk/create a child for each character, then mark the last node as end.
  3. search: walk the characters; if any is missing, fail — otherwise check the end flag.
  4. startsWith: same walk, but don't check the end flag — just that the path exists.
