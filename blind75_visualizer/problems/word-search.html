Approach
board = [["A","B","C"],["S","F","C"],["A","D","E"]], word = "ABCCED" → True
  1. Try starting the DFS from every cell that matches the word's first letter.
  2. At each step, if the current cell matches word[i], mark it visited (e.g. overwrite temporarily) and explore all 4 neighbors for word[i+1].
  3. Restore the cell after exploring (backtrack) so other paths can use it.
  4. Success when the recursion reaches the end of the word.
