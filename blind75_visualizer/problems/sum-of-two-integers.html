Sum of Two Integers

Medium
Bit Manipulation

LeetCode #371 · Add two integers without using the + or - operators.

solution.pyO(1) — bounded by 32 bits time · O(1) space
1class Solution:2 def getSum(self, a: int, b: int) -> int:3 mask = 0xFFFFFFFF4 while b & mask:5 a, b = a ^ b, (a & b) << 16 result = (a ^ b) & mask7 return result if result <= 0x7FFFFFFF else ~(result ^ mask)
Time O(1) — bounded by 32 bits Space O(1)
Approach
a = 1, b = 2 → 3
  1. XOR (a ^ b) adds bits without carrying; AND (a & b) shifted left by 1 gives exactly the carry bits.
  2. Repeat 'sum, carry = a^b, (a&b)<<1' until there's no carry left — this is how binary adders work.
  3. A mask limits everything to 32 bits, since Python integers don't naturally overflow like C integers.
  4. Convert back from the 32-bit unsigned representation to a signed Python int at the end.
