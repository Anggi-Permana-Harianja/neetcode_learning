Longest Palindromic Substring

LeetCode #5 · Find the longest substring of s that reads the same forward and backward.

solution.pyO(n²) time · O(1) space
1class Solution:2 def longestPalindrome(self, s: str) -> str:3 best = ""4 5 def expand(l: int, r: int) -> str:6 while l >= 0 and r < len(s) and s[l] == s[r]:7 l -= 18 r += 19 return s[l + 1:r]10 11 for i in range(len(s)):12 odd = expand(i, i)13 even = expand(i, i + 1)14 best = max(best, odd, even, key=len)15 return best
Time O(n²) Space O(1)
Approach
s = "babad" → "bab" (or "aba")
  1. Every palindrome has a center — either one character (odd length) or between two characters (even length).
  2. For each possible center, expand outward while the characters on both sides match.
  3. Try both an odd-length expansion (center = i) and even-length expansion (center = i, i+1) for every index.
  4. Track the longest match found across all centers.
