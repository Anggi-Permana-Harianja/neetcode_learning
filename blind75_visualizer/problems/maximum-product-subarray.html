LeetCode #152 · Find the contiguous subarray with the largest product.

solution.pyO(n) time · O(1) space
1from typing import List2 3class Solution:4 def maxProduct(self, nums: List[int]) -> int:5 result = nums[0]6 cur_min, cur_max = 1, 17 for num in nums:8 candidates = (num, cur_max * num, cur_min * num)9 cur_max, cur_min = max(candidates), min(candidates)10 result = max(result, cur_max)11 return result
Time O(n) Space O(1)
Approach
nums = [2,3,-2,4] → 6 ([2,3])
  1. Unlike max subarray sum, a large negative product can become the best positive product after multiplying by another negative — so track both a running max AND a running min.
  2. At each number, the new max/min are the best/worst of: the number alone, max*number, min*number.
  3. Update the global result with the running max after each step.
