LeetCode #56 · Merge all overlapping intervals in an unsorted list.

solution.pyO(n log n) time · O(n) space
1from typing import List2 3class Solution:4 def merge(self, intervals: List[List[int]]) -> List[List[int]]:5 intervals.sort(key=lambda pair: pair[0])6 result = [intervals[0]]7 for start, end in intervals[1:]:8 if start <= result[-1][1]:9 result[-1][1] = max(result[-1][1], end)10 else:11 result.append([start, end])12 return result
Time O(n log n) Space O(n)
Approach
intervals = [[1,3],[2,6],[8,10],[15,18]] → [[1,6],[8,10],[15,18]]
  1. Sort intervals by start time — this guarantees any overlap involves consecutive intervals.
  2. Walk through, keeping a 'current merged interval' (initially the first).
  3. If the next interval's start is <= the current merged interval's end, they overlap — extend the end to cover both.
  4. Otherwise, close off the current merged interval and start a new one.
