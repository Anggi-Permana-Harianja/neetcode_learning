LeetCode #268 · Find the one missing number from a range [0, n] given n distinct numbers.

solution.pyO(n) time · O(1) space
1from typing import List2 3class Solution:4 def missingNumber(self, nums: List[int]) -> int:5 n = len(nums)6 expected = n * (n + 1) // 27 return expected - sum(nums)
Time O(n) Space O(1)
Approach
nums = [3,0,1] → 2
  1. The sum of 0..n has a closed form: n * (n + 1) / 2.
  2. Subtract the actual sum of nums from the expected sum — whatever's left over is the missing number.
  3. (An XOR-based version works too: XOR every index and every value together; everything pairs off except the missing one — either approach is O(n)/O(1).)
