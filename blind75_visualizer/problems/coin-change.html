LeetCode #322 · Find the fewest coins needed to make up a given amount (or -1 if impossible).

solution.pyO(amount · number of coin types) time · O(amount) space
1from typing import List2 3class Solution:4 def coinChange(self, coins: List[int], amount: int) -> int:5 dp = [0] + [float("inf")] * amount6 for a in range(1, amount + 1):7 for coin in coins:8 if coin <= a:9 dp[a] = min(dp[a], dp[a - coin] + 1)10 return dp[amount] if dp[amount] != float("inf") else -1
Time O(amount · number of coin types) Space O(amount)
Approach
coins = [1,2,5], amount = 11 → 3 (5+5+1)
  1. Bottom-up DP: dp[a] = fewest coins to make amount a, with dp[0] = 0.
  2. For every amount from 1 up to the target, try every coin: if the coin fits, dp[a] = min(dp[a], dp[a - coin] + 1).
  3. Initialize all dp values (besides 0) to infinity so unreachable amounts stay unreachable.
  4. If dp[amount] is still infinity at the end, it's impossible — return -1.
