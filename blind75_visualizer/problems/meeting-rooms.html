LeetCode #252 · Determine if a person could attend every meeting (no time overlaps).

solution.pyO(n log n) time · O(1) space
1from typing import List2 3class Solution:4 def canAttendMeetings(self, intervals: List[List[int]]) -> bool:5 intervals.sort(key=lambda pair: pair[0])6 for i in range(1, len(intervals)):7 if intervals[i][0] < intervals[i - 1][1]:8 return False9 return True
Time O(n log n) Space O(1)
Approach
intervals = [[0,30],[5,10],[15,20]] → False
  1. Sort meetings by start time.
  2. Walk through consecutive pairs: if a meeting starts before the previous one ends, they overlap.
  3. Any single overlap means the person can't attend all meetings.
