Find Median from Data Stream

solution.pyO(log n) add, O(1) query time · O(n) space
1import heapq2 3class MedianFinder:4 def __init__(self):5 self.small = [] # max-heap (negated)6 self.large = [] # min-heap7 8 def addNum(self, num: int) -> None:9 heapq.heappush(self.small, -num)10 heapq.heappush(self.large, -heapq.heappop(self.small))11 if len(self.large) > len(self.small):12 heapq.heappush(self.small, -heapq.heappop(self.large))13 14 def findMedian(self) -> float:15 if len(self.small) > len(self.large):16 return -self.small[0]17 return (-self.small[0] + self.large[0]) / 2
Time O(log n) add, O(1) query Space O(n)
Approach
addNum(1), addNum(2) → median 1.5; addNum(3) → median 2
  1. Split numbers across two heaps: 'small' (max-heap, via negation) for the lower half, 'large' (min-heap) for the upper half.
  2. Always push into small first, then move its top into large to keep values properly partitioned.
  3. Rebalance so small never has more than one extra element compared to large.
  4. If small has one more element, it holds the median; otherwise average the two tops.
