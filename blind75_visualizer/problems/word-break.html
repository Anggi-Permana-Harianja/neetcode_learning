LeetCode #139 · Check if a string can be segmented into words from a given dictionary.

solution.pyO(n²) time · O(n) space
1from typing import List2 3class Solution:4 def wordBreak(self, s: str, wordDict: List[str]) -> bool:5 words = set(wordDict)6 n = len(s)7 dp = [False] * (n + 1)8 dp[0] = True9 for i in range(1, n + 1):10 for j in range(i):11 if dp[j] and s[j:i] in words:12 dp[i] = True13 break14 return dp[n]
Time O(n²) Space O(n)
Approach
s = "leetcode", wordDict = ["leet","code"] → True
  1. dp[i] = True if s[:i] can be fully segmented using dictionary words.
  2. dp[0] = True (empty prefix trivially segments).
  3. For each end position i, try every split point j < i: if dp[j] is True and s[j:i] is a dictionary word, then dp[i] is True.
  4. A set for the dictionary makes each substring check O(1) average.
