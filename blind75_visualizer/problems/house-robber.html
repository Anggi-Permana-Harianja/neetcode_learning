LeetCode #198 · Maximize loot from houses in a row, without robbing two adjacent houses.

solution.pyO(n) time · O(1) space
1from typing import List2 3class Solution:4 def rob(self, nums: List[int]) -> int:5 prev, curr = 0, 06 for num in nums:7 prev, curr = curr, max(curr, prev + num)8 return curr
Time O(n) Space O(1)
Approach
nums = [2,7,9,3,1] → 12 (rob 2 + 9 + 1)
  1. At each house, choose: skip it (keep the best total so far) or rob it (that house's value + best total from two houses back).
  2. Track only the last two running best values (prev, curr) instead of a full DP array.
  3. curr becomes max(curr, prev + num) — either the total unchanged, or rob this house.
