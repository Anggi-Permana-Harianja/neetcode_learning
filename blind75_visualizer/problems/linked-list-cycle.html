Approach
3 → 2 → 0 → -4 → (back to 2) → True
  1. Use Floyd's tortoise and hare: a slow pointer moves 1 step, a fast pointer moves 2 steps.
  2. If there's no cycle, fast (or fast.next) reaches None and we return False.
  3. If there is a cycle, the fast pointer eventually laps the slow pointer and they meet.
  4. A meeting (slow is fast) proves a cycle exists.
