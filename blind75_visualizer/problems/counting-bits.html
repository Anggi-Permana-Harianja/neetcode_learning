LeetCode #338 · For every number 0..n, count its number of set bits.

solution.pyO(n) time · O(n) space
1from typing import List2 3class Solution:4 def countBits(self, n: int) -> List[int]:5 dp = [0] * (n + 1)6 for i in range(1, n + 1):7 dp[i] = dp[i >> 1] + (i & 1)8 return dp
Time O(n) Space O(n)
Approach
n = 5 → [0,1,1,2,1,2]
  1. Reuse previously computed answers instead of counting bits from scratch each time.
  2. i >> 1 is i with its lowest bit dropped, and i & 1 is that dropped bit itself.
  3. So dp[i] = dp[i >> 1] + (i & 1) — the bit count of i is the bit count of i//2 plus whether i is odd.
