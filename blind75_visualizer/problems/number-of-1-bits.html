LeetCode #191 · Count the number of set bits (1s) in an integer's binary representation.

solution.pyO(k) — k = number of set bits time · O(1) space
1class Solution:2 def hammingWeight(self, n: int) -> int:3 count = 04 while n:5 n &= n - 16 count += 17 return count
Time O(k) — k = number of set bits Space O(1)
Approach
n = 11 (1011) → 3
  1. n & (n - 1) clears the lowest set bit of n (a well-known bit trick).
  2. Repeat that operation, counting each time, until n becomes 0.
  3. The number of iterations equals the number of set bits — faster than checking all 32 bit positions when few are set.
