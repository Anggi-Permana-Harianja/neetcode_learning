1from typing import Optional2 3class ListNode:4 def __init__(self, val=0, next=None):5 self.val = val6 self.next = next7 8class Solution:9 def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:10 prev = None11 curr = head12 while curr:13 nxt = curr.next14 curr.next = prev15 prev = curr16 curr = nxt17 return prev
Time O(n) Space O(1)
Approach
1 → 2 → 3 → 4 becomes 4 → 3 → 2 → 1
  1. Walk the list with two pointers: prev (starts None) and curr (starts head).
  2. At each node, save curr.next before overwriting it, then point curr.next back to prev.
  3. Advance prev to curr and curr to the saved next node.
  4. When curr is None, prev is the new head.
