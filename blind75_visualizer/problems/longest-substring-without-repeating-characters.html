LeetCode #3 · Find the length of the longest substring with no repeated characters.

solution.pyO(n) time · O(min(n, charset)) space
1class Solution:2 def lengthOfLongestSubstring(self, s: str) -> int:3 seen = {}4 left = 05 best = 06 for right, ch in enumerate(s):7 if ch in seen and seen[ch] >= left:8 left = seen[ch] + 19 seen[ch] = right10 best = max(best, right - left + 1)11 return best
Time O(n) Space O(min(n, charset))
Approach
s = "abcabcbb" → 3 ("abc")
  1. Maintain a window [left, right] with a map of the last index each character was seen at.
  2. When the character at right was already seen inside the current window, jump left past that occurrence.
  3. Update the character's last-seen index every step.
  4. Track the max window length (right - left + 1) as you slide.
