LeetCode #269 · Derive a valid character ordering for an alien language from a sorted word list.

solution.pyO(C) — total characters across all words time · O(1) — bounded alphabet space

Approach
words = ["wrt","wrf","er","ett","rftt"] → "wertf"
  1. Compare each pair of adjacent words: the first differing character tells you one letter comes before another — add that as a directed edge.
  2. If one word is a prefix of the next, that's fine; if the longer word comes first, the ordering is invalid.
  3. Topologically sort the resulting letter graph via DFS, marking nodes 'visiting' then 'done' to detect cycles (an invalid ordering).
  4. Append each letter to the order list as its DFS finishes, then reverse — that's standard post-order topological sort.
