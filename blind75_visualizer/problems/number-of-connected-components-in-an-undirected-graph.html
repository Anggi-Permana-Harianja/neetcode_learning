Approach
n = 5, edges = [[0,1],[1,2],[3,4]] → 2
  1. Union-Find (Disjoint Set Union): start with n separate components, one per node.
  2. For each edge, union its two endpoints; if they were already in the same set, no component count changes.
  3. Path compression (find) and union by rank keep operations nearly O(1) amortized.
  4. Each successful union merges two components into one, so decrement the running count.
