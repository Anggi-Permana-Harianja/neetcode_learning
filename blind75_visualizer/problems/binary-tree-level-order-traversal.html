Approach
[3,9,20,null,null,15,7] → [[3],[9,20],[15,7]]
  1. BFS with a queue, but process one full level at a time.
  2. Before dequeuing, note the current queue size — that's exactly this level's node count.
  3. Pop that many nodes, collect their values, and enqueue their children for the next level.
  4. Append each level's collected values to the result.
