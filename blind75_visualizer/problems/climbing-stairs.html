LeetCode #70 · Count distinct ways to climb n stairs, taking 1 or 2 steps at a time.

solution.pyO(n) time · O(1) space
1class Solution:2 def climbStairs(self, n: int) -> int:3 if n <= 2:4 return n5 prev, curr = 1, 26 for _ in range(3, n + 1):7 prev, curr = curr, prev + curr8 return curr
Time O(n) Space O(1)
Approach
n = 5 → 8
  1. The number of ways to reach step n is ways(n-1) + ways(n-2) — you arrive either from one step back or two steps back. This is Fibonacci.
  2. Base cases: 1 way to reach step 1, 2 ways to reach step 2.
  3. Iterate up from step 3, keeping only the last two values instead of a full array.
