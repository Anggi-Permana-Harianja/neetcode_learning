Approach
preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
  1. Preorder's first element is always the current subtree's root.
  2. Find that value's position in inorder — everything left of it is the left subtree, everything right is the right subtree.
  3. A hash map from value → inorder index makes that lookup O(1).
  4. Advance a shared preorder index and recurse, building left before right (matching preorder's order).
