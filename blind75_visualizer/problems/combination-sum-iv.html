LeetCode #377 · Count the number of ordered sequences from nums that sum to target (order matters).

solution.pyO(target · len(nums)) time · O(target) space
1from typing import List2 3class Solution:4 def combinationSum4(self, nums: List[int], target: int) -> int:5 dp = [1] + [0] * target6 for t in range(1, target + 1):7 for num in nums:8 if num <= t:9 dp[t] += dp[t - num]10 return dp[target]

Approach
nums = [1,2,3], target = 4 → 7
  1. Unlike Combination Sum, order matters here, so this is really a 'count ways to climb to target using steps of size nums[i]' problem.
  2. dp[t] = number of ways to reach exactly total t; dp[0] = 1 (one way: use nothing).
  3. For each target t from 1 upward, sum dp[t - num] over every num that fits.
  4. This naturally counts different orderings of the same numbers as distinct.
