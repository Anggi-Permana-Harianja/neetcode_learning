LeetCode #62 · Count paths from top-left to bottom-right of an m x n grid, moving only right or down.

solution.pyO(m · n) time · O(n) space
1class Solution:2 def uniquePaths(self, m: int, n: int) -> int:3 row = [1] * n4 for _ in range(m - 1):5 for c in range(1, n):6 row[c] += row[c - 1]7 return row[-1]
Time O(m · n) Space O(n)
Approach
m = 3, n = 7 → 28
  1. The number of ways to reach a cell is the sum of ways to reach the cell above it and the cell to its left.
  2. Only one row needs to be kept in memory at a time — process row by row, updating in place left to right.
  3. The first row and first column each have exactly 1 way (straight line), which the initialization/update naturally preserves.
