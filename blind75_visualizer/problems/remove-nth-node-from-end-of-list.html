LeetCode #19 · Remove the nth node from the end of the list in one pass.

solution.pyO(n) time · O(1) space
1from typing import Optional2 3class ListNode:4 def __init__(self, val=0, next=None):5 self.val = val6 self.next = next7 8class Solution:9 def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:10 dummy = ListNode(0, head)11 fast = slow = dummy12 for _ in range(n):13 fast = fast.next14 while fast.next:15 fast = fast.next16 slow = slow.next17 slow.next = slow.next.next18 return dummy.next
Time O(n) Space O(1)
Approach
1→2→3→4→5, n = 2 → 1→2→3→5
  1. Use a dummy node before head so removing the actual head is handled uniformly.
  2. Advance a fast pointer n steps ahead of a slow pointer.
  3. Move both pointers together until fast reaches the last node.
  4. slow is now just before the node to remove — unlink it with slow.next = slow.next.next.
