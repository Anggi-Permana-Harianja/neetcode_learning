LeetCode #261 · Check whether n nodes and a list of edges form a valid tree.

solution.pyO(E · α(n)) time · O(n) space
1from typing import List2 3class Solution:4 def validTree(self, n: int, edges: List[List[int]]) -> bool:5 if len(edges) != n - 1:6 return False7 parent = list(range(n))8 9 def find(x: int) -> int:10 while parent[x] != x:11 parent[x] = parent[parent[x]]12 x = parent[x]13 return x14 15 def union(a: int, b: int) -> bool:16 ra, rb = find(a), find(b)17 if ra == rb:18 return False19 parent[ra] = rb20 return True21 22 return all(union(a, b) for a, b in edges)
Time O(E · α(n)) Space O(n)
Approach
n = 5, edges = [[0,1],[0,2],[0,3],[1,4]] → True
  1. A valid tree on n nodes must have exactly n - 1 edges — check that first as a cheap filter.
  2. With exactly n - 1 edges, the graph is a tree iff it's fully connected with no cycles.
  3. Union-Find each edge: if two endpoints are already connected, adding this edge creates a cycle — not a tree.
  4. If every union succeeds (no cycle found) and the edge count matched, it's a valid tree.
