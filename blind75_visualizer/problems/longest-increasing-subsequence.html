LeetCode #300 · Find the length of the longest strictly increasing subsequence.

1from typing import List2import bisect3 4class Solution:5 def lengthOfLIS(self, nums: List[int]) -> int:6 tails = []7 for num in nums:8 i = bisect.bisect_left(tails, num)9 if i == len(tails):10 tails.append(num)11 else:12 tails[i] = num13 return len(tails)

Approach
nums = [10,9,2,5,3,7,101,18] → 4 ([2,3,7,101] or [2,3,7,18])
  1. Maintain 'tails': tails[k] is the smallest possible tail value of an increasing subsequence of length k+1.
  2. For each number, binary search tails for the leftmost position where it can replace an existing value (or extend the list).
  3. If it extends past the end, the LIS length grows by one; otherwise it just makes a future extension easier by lowering a tail.
  4. The final length of tails is the LIS length (the array itself may not be a real subsequence, but its length is correct).
