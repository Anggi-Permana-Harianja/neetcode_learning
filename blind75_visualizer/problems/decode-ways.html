LeetCode #91 · Count ways to decode a digit string where 'A'-'Z' map to 1-26.

solution.pyO(n) time · O(1) space
1class Solution:2 def numDecodings(self, s: str) -> int:3 if not s or s[0] == "0":4 return 05 n = len(s)6 prev, curr = 1, 17 for i in range(1, n):8 count = 09 if s[i] != "0":10 count += curr11 two_digit = int(s[i - 1:i + 1])12 if 10 <= two_digit <= 26:13 count += prev14 prev, curr = curr, count15 return curr
Time O(n) Space O(1)
Approach
"226" → 3 ("BZ", "VF", "BBF")
  1. dp[i] = number of ways to decode the first i characters.
  2. A single digit s[i-1] contributes dp[i-1] ways if it's not '0'.
  3. The two-digit combo s[i-2:i] contributes dp[i-2] ways if it's between 10 and 26.
  4. Sum both contributions; track only the last two dp values for O(1) space.
