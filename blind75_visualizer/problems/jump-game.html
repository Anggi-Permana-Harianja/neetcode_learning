LeetCode #55 · Determine if you can reach the last index, where nums[i] is the max jump length from i.

solution.pyO(n) time · O(1) space

Time O(n) Space O(1)
Approach
nums = [2,3,1,1,4] → True
  1. Work backward from the last index, tracking the leftmost index ('goal') known to be able to reach the end.
  2. For each index i (right to left), if i + nums[i] can reach the current goal, then i itself becomes the new, closer goal.
  3. If the goal is pulled all the way back to index 0, the start can reach the end.
