LeetCode #100 · Check whether two binary trees are structurally identical with the same values.

solution.pyO(n) time · O(h) space
1from typing import Optional2 3class TreeNode:4 def __init__(self, val=0, left=None, right=None):5 self.val = val6 self.left = left7 self.right = right8 9class Solution:10 def isSameTree(self, p: Optional[TreeNode], q: Optional[TreeNode]) -> bool:11 if not p and not q:12 return True13 if not p or not q or p.val != q.val:14 return False15 return self.isSameTree(p.left, q.left) and self.isSameTree(p.right, q.right)
Time O(n) Space O(h)
Approach
p = [1,2,3], q = [1,2,3] → True
  1. If both nodes are None, they match at this position.
  2. If exactly one is None, or their values differ, the trees don't match.
  3. Otherwise recurse on both left subtrees and both right subtrees, requiring both to match.
