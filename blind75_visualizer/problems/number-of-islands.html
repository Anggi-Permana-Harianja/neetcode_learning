LeetCode #200 · Count the number of connected groups of '1's in a grid.

Approach
[["1","1","0"],["0","1","0"],["0","0","1"]] → 2
  1. Scan every cell; whenever an unvisited '1' is found, that's a brand new island — increment the count.
  2. BFS (or DFS) outward from that cell across all connected '1's, marking each visited so it isn't recounted.
  3. Only explore the 4 orthogonal neighbors (up/down/left/right).
  4. Continue scanning after the flood-fill returns.
