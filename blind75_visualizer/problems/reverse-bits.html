LeetCode #190 · Reverse the bits of a 32-bit unsigned integer.

solution.pyO(1) — always 32 iterations time · O(1) space
1class Solution:2 def reverseBits(self, n: int) -> int:3 result = 04 for i in range(32):5 bit = (n >> i) & 16 result |= bit << (31 - i)7 return result
Time O(1) — always 32 iterations Space O(1)
Approach
n = 00000010100101000001111010011100 → 00111001011110000010100101000000
  1. For each of the 32 bit positions, extract bit i of n with (n >> i) & 1.
  2. Place that bit into the mirrored position (31 - i) of the result using OR and a left shift.
  3. After all 32 positions are processed, the result is n with its bits reversed.
