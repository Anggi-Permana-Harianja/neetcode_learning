Time O(m · n) worst case Space O(h)
Approach
root = [3,4,5,1,2], subRoot = [4,1,2] → True
  1. At each node of root, check if the tree rooted there is identical to subRoot (reusing a same-tree check).
  2. If it matches, we're done.
  3. Otherwise recurse into root's left and right children and try again.
  4. An empty root only matches an empty subRoot.
