Approach
board[i][j] is a digit "1"-"9" or "."
  1. Keep one set per row, per column, and per 3×3 box (9 of each) to track digits already placed.
  2. Scan every cell of the 9x9 board; skip empty cells (".").
  3. Compute which box a cell belongs to with (r // 3) * 3 + c // 3.
  4. If the digit is already in that row's, column's, or box's set, the board is invalid — return False.
  5. Otherwise record the digit in all three sets and continue; no conflicts after a full scan means it's valid.
