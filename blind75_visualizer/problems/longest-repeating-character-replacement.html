Time O(n) Space O(1) — 26 letters
Approach
s = "AABABBA", k = 1 → 4
  1. Grow a window while tracking counts of each letter inside it.
  2. A window is valid if (window length - most frequent letter's count) <= k — that's how many replacements it needs.
  3. If the window becomes invalid, shrink it from the left by one.
  4. Track the best valid window length throughout; max_count doesn't need to shrink accurately since only its peak matters.
