LeetCode #253 · Find the minimum number of meeting rooms required to host all meetings.

solution.pyO(n log n) time · O(n) space
1from typing import List2import heapq3 4class Solution:5 def minMeetingRooms(self, intervals: List[List[int]]) -> int:6 intervals.sort(key=lambda pair: pair[0])7 heap = [] # end times of rooms in use8 for start, end in intervals:9 if heap and heap[0] <= start:10 heapq.heapreplace(heap, end)11 else:12 heapq.heappush(heap, end)13 return len(heap)
Time O(n log n) Space O(n)
Approach
intervals = [[0,30],[5,10],[15,20]] → 2
  1. Sort meetings by start time, then simulate room usage with a min-heap of end times.
  2. For each meeting, if the earliest-ending room (heap top) is free by this meeting's start, reuse that room (replace its end time).
  3. Otherwise no existing room is free yet — allocate a new one by pushing this meeting's end time.
  4. The heap's final size is the number of rooms simultaneously in use at peak — the answer.
