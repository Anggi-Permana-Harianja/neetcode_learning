Approach
root = [3,1,4,null,2], k = 1 → 1
  1. An inorder traversal of a BST visits values in ascending order.
  2. Simulate that traversal iteratively with an explicit stack instead of recursion.
  3. Push left children until there are none, then pop, count it, and move to the right child.
  4. The kth node popped is the answer — no need to build the full sorted list.
