Approach
addWord("bad"); search("b.d") → True
  1. Store words in a trie exactly like Implement Trie.
  2. Search with DFS instead of a straight walk, to handle backtracking.
  3. On a normal letter, follow that one child if it exists.
  4. On '.', try every child at that level — if any path leads to a match, return True.
