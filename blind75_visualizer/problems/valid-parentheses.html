LeetCode #20 · Check if brackets in a string are properly opened and closed in order.

solution.pyO(n) time · O(n) space
1class Solution:2 def isValid(self, s: str) -> bool:3 pairs = {")": "(", "]": "[", "}": "{"}4 stack = []5 for ch in s:6 if ch in pairs:7 if not stack or stack.pop() != pairs[ch]:8 return False9 else:10 stack.append(ch)11 return not stack
Time O(n) Space O(n)
Approach
s = "()[]{}" → True
  1. Push opening brackets onto a stack as you scan left to right.
  2. On a closing bracket, it must match the bracket on top of the stack — pop and compare.
  3. If the stack is empty or the top doesn't match, the string is invalid.
  4. At the end, the stack must be empty — no unclosed brackets remain.
