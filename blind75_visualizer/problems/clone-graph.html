Approach
adjList = [[2,4],[1,3],[2,4],[1,3]] → identical structure, new nodes
  1. Keep a map from original node → its clone, so each node is only cloned once (handles cycles).
  2. DFS from the given node: if already cloned, return the existing clone.
  3. Otherwise create a clone, register it in the map immediately (before recursing) to break cycles, then recursively clone and attach each neighbor.
