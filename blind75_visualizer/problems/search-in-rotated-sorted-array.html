Approach
nums = [4,5,6,7,0,1,2], target = 0 → 4
  1. At each step, at least one half of [left, mid] or [mid, right] is normally sorted — figure out which.
  2. If the left half is sorted, check whether target falls within its range to decide which half to search.
  3. Otherwise the right half is sorted — apply the same range check there.
  4. Narrow left/right accordingly each step, same as standard binary search.
